桌面信息屏 · 网页刷机

不用装任何软件，用电脑上的 Chrome 或 Edge 就能把固件刷进乐鑫 ESP32-S3-BOX-3。以后的新版本设备会自己在线升级。

一键刷机

这个浏览器不支持网页刷机，请用电脑上的 Chrome 或 Edge 打开这个网页（手机和 Safari、Firefox 都不行）。 网页刷机需要 https 地址，请从 GitHub Pages 的网址打开。

步骤

  1. 用能传数据的 USB-C 线把 BOX-3 接到电脑（只能充电的线不行）。
  2. 点上面的按钮，在弹出的列表里选板子的串口，点「连接」。Windows 上通常叫 USB JTAG/serial debug unit。
  3. 选「安装」。第一次刷建议勾选清除设备，大约 1～2 分钟。
  4. 刷完板子会重启，屏幕上显示一个 DeskScreen-XXXX 热点。用手机连上它，在弹出的网页里选家里的 WiFi（只支持 2.4G）。
  5. 连上网后，长按屏幕 2 秒打开快捷设置，用手机扫二维码打开设置网页。第一次打开要输入屏幕上显示的 6 位配对码。

连不上板子？

  • 换一根 USB 线或换一个 USB 口，别用扩展坞。
  • 按住板子上的 BOOT 键不放，再按一下 RESET（复位）键，松开 BOOT，然后重新点按钮。
  • 还是不行，可以用乐鑫的 esptool 网页版，地址填 0x0，选 Release 里的 firmware-box3-merged.bin。
